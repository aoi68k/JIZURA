# JIZURA bluesky-view

Bluesky のタイムラインを **60 秒に 1 回** 自動確認し、読み込んだメッセージ（投稿者名、アイコン、メッセージ内容）を **JIZURA の文字PV** としてリアルタイムに演出・表示します。

## 起動方法

### 簡単起動（Windows）
`bluesky/起動.bat` をダブルクリックするだけです。
（.NET 9 SDK または Python 3 があれば自動で起動します）

ブラウザで `http://localhost:8791/` が自動で開き、Bluesky の投稿が JIZURA のタイポグラフィ演出で再生されます。

### コマンドラインからの起動

```bash
# .NET 9 bridge で起動する場合
dotnet run --project bluesky/bridge -c Release -- [--port 8791] [--no-browser]

# または Python で起動する場合
python bluesky/server.py
```

## 主な機能と特徴

1. **60 秒に 1 回のタイムライン自動確認**:
   - バックグラウンドで 60 秒ごとに Bluesky をチェックし、新着投稿があれば自動でキューに追加します。
   - 画面の HUD に次回確認までのカウントダウン（`確認: 59s` ...）が表示され、手動で「更新 🔄」を押すこともできます。
2. **名前・アイコン・メッセージ内容の完全表示**:
   - **メッセージ内容**: JIZURA のキネティックタイポグラフィ・リリックモーションによって、文章の長さやリズムに合わせた美しい文字PVとしてカット割り再生されます。
   - **アイコン＆名前**: 画面上部および Canvas 内に投稿者のアバター画像（円形クリッピング＋シャドウ）、名前、`@handle`、🦋 バッジ、プログレスバーが美しく描画されます。配信ソフトや動画キャプチャでも綺麗に記録されます。
3. **添付画像の背景 (BG) 自動表示**:
   - ポストにイラストや写真などの絵が貼られている場合、それを**全画面背景（BG）**として自動合成します。
   - 再生時間に合わせて緩やかにズームする映画的演出（Ken Burns エフェクト）や、文字PVの歌詞が美しく際立つ暗幕・ビネット処理が自動で適用されます。
   - 絵がない投稿の場合は、通常の JIZURA スタイル背景で再生されます。
4. **2 つの取得モード**:
   - **指定ユーザーの投稿（認証不要）**: ハンドル名（例: `bsky.app`, `alice.bsky.social` など）を入力するだけで、ログイン不要で誰でもすぐに動かせます。
   - **自分のタイムライン（要ログイン）**: Bluesky のハンドル名とアプリパスワード（App Password）を設定すれば、自分がフォローしているアカウントのタイムラインを丸ごと流せます。
5. **JIZURA 本体への非侵襲設計**:
   - JIZURA 本体のソースコード（`src/` 配下）を一切改変せず、`bluesky` フォルダ内で完全に自己完結しています。
   - サーバーはリクエスト時に `src/*.js` を自動結合して JIZURA エンジンを配信するため、ビルド手順不要で本体のアップデートやカスタマイズがそのまま反映されます。


## 操作方法

画面下部のバー（マウスを動かすと表示、3.5 秒でフェードアウトします）

| 項目 | ショートカット | 内容 |
| --- | --- | --- |
| ◀ 前 / 次 ▶ | `←` / `→` | 前後の投稿に手動で移動します |
| 一時停止 / 再開 | `Space` | じっくり読みたいときに一時停止できます |
| 演出 | — | 「おまかせ（投稿ごと）」は投稿ごとにスタイル・演出を自動選択。固定スタイルも選べます |
| 比率 | — | 16:9 / 9:16 / 1:1 / 4:3 / 21:9 から選択可能 |
| 背景 | — | 「演出あり」または「透明（OBS合成用）」 |
| 別の演出 | `R` | 今の投稿の演出・シードを引き直します |
| 更新 🔄 | — | 今すぐ Bluesky から最新投稿を取得します |
| 設定 ⚙ | — | 取得モード、アカウント、アプリパスワード、確認秒数、表示秒数を変更できます |
| 全画面 | `F` | ブラウザの全画面表示 |
| HUD固定 | `H` | 下部バーの自動非表示・常時表示を切り替えます |

### OBS などの配信ソフトでの利用

OBS の「ブラウザソース」で以下のように URL を指定できます：
- `http://localhost:8791/?hud=0`：下部操作バーを出さずに表示
- `http://localhost:8791/?hud=0&bg=clear`：背景を完全透明にしてゲームやデスクトップ画面に重ねて表示
- `http://localhost:8791/?card=0`：HTML側のカードを非表示にし、Canvas 内の描画のみに集約

## 仕組み

```
Bluesky (AT Protocol) ──(60秒ポーリング)──▶ bridge (C# / Python, localhost:8791)
                                            ├ /api/timeline   タイムライン・投稿データ
                                            ├ /api/config     モード・アカウント設定
                                            ├ /api/proxy-image  アバター画像のCORSキャッシュプロキシ
                                            ├ /jizura.js      src/*.js をその場で連結した JIZURA エンジン
                                            └ /               www/（ビューアー）
ブラウザ (www/app.js):
  投稿本文をカット割り・歌詞データに変換
  → J.plan でリリックモーション生成
  → J.Renderer で文字PV描画
  → Canvas 内にアバターアイコン・名前をオーバーレイ合成
```
