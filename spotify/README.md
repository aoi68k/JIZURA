# JIZURA spotify-view

Windows 版 Spotify で再生中の曲に合わせて、**LRCLIB**（オープンソース向け歌詞データベース）から取得した歌詞を **JIZURA の文字PV** としてリアルタイム表示します。
Spotify の開発者登録や API キーは不要です（仕組みは SpotifyLyrics と同じく Windows のメディアセッションを使います）。

## 起動

.NET 9 SDK を入れた Windows で `spotify/起動.bat` を実行します（初回はビルドが走ります）。
ブラウザで `http://localhost:8790/` が開くので、Spotify で曲を再生してください。

```
dotnet run --project spotify/bridge -c Release -- [--port 8790] [--no-browser] [--root <JIZURAフォルダー>]
```

## 操作

画面下部のバー（マウスを動かすと表示、3 秒で消えます）

| 項目 | 内容 |
| --- | --- |
| 演出 | 「おまかせ（曲ごと）」は曲ごとに決まったスタイル・演出を自動で選びます。スタイルを固定することもできます |
| 比率 | 16:9 / 9:16 / 1:1 / 4:3 / 21:9 |
| 背景 | 演出あり（JIZURA の背景・背景グラフィックごと表示）／透明（歌詞と装飾だけ。通常のウィンドウでは市松模様で確認できます） |
| 別の演出 (R) | 今の曲の演出を引き直します |
| 補正 (← / →) | 0.1 秒単位。＋で歌詞を遅らせ、−で早めます |
| 歌詞を再取得 | キャッシュを使わずに LRCLIB から取り直します |
| LRC読込 | 手持ちの `.lrc` または `.txt` ファイルを読み込みます（ドラッグ＆ドロップでも可能） |
| 全画面 (F) | ブラウザの全画面表示 |
| OBS用URL | OBS のブラウザソースに設定するURL（`http://localhost:8790/?obs`）をクリップボードにコピー |

`H` でバーを常時表示に切り替えます。

### OBS Studio での利用方法（背景透過）

1. OBS で「ソース」の **＋** を押し、**「ブラウザ」** を追加します。
2. **URL** に `http://localhost:8790/?obs` を入力します（または操作バーの「OBS用URL」ボタンでコピーできます）。
3. **幅** を `1920`、**高さ** を `1080`（配信解像度に合わせて）設定し、「OK」を押します。
4. これで背景が完全に透明になり、文字PVの歌詞と演出・装飾だけがゲームや配信映像の上に透過表示されます（操作バーやカーソル、待機ロゴも自動で非表示になります）。

## 歌詞の検索・取得仕様

1. **LRCLIB 公開API**: オープンソース音楽アプリ向けに公式公開されているコミュニティ主導のデータベース（https://lrclib.net）を利用。
2. **タイトル正規化**: Spotify の曲名に含まれる `(feat. ...)`、`[TV Size]`、`- Remastered`、`- オリジナル・カラオケ` などの表記揺れを除去して検索精度を向上。
3. **通常歌詞（自動配分）**: LRCLIB に同期タイムスタンプがない曲でも、通常テキスト歌詞が存在すれば曲の長さに合わせて自動で時間配分し、JIZURA 上に歌詞アニメーションとして展開。
4. **手持ち歌詞**: `.lrc` や `.txt` をブラウザにドラッグ＆ドロップすれば、その場で反映。

## 仕組み

```
Spotify ──(Windows メディアセッション)──▶ bridge (C#, localhost:8790)
                                          ├ /api/now      曲名・アーティスト・再生位置
                                          ├ /api/lyrics   LRCLIB 歌詞（%LOCALAPPDATA%/JizuraSpotify/cache にキャッシュ）
                                          ├ /jizura.js    src/*.js をその場で連結した JIZURA エンジン
                                          └ /             www/（ビューアー）
ブラウザ (www/app.js): 再生位置を 0.5 秒ごとに取得して補間 → LRC を JIZURA の歌詞に変換 → J.plan → J.Renderer で描画
```

- エンジンはリクエストのたびに `src/*.js` から組み立てる（変更があったときだけ）ので、`build.py` を実行しなくても本体の変更がそのまま反映されます。
- LRC の空行・♪行、行のあとの長い空白は `[間奏]` に変換し、背景と装飾だけの場面になります。
- 歌詞中の `/ * |` などは JIZURA の記法と衝突しないよう全角に置き換えます。
- 作詞・作曲などのクレジット行は自動認識して間奏として扱い、歌い出しから自然に歌詞演出に入ります。

## 制約

- 再生位置の精度・更新間隔は Spotify の動作に依存します。ずれる場合は「補正」で合わせてください。
- スマホ単独再生は対象外です（PC の Spotify アプリが必要）。
- LRCLIB の稼働や全曲の収録は保証されません。フォントは Google Fonts から読み込むためインターネット接続が必要です。
